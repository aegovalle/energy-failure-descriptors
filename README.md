# Energy and failure select different descriptors

Code and frozen blind-validation protocol for the manuscript

> A.E. Gómez-Ovalle and C. Ramírez Ovalle, *Energy and failure select different descriptors:
> counterexample-driven descriptor discovery in heterogeneous solids*, submitted to the
> International Journal of Solids and Structures (2026).

## Contents

| Path | Content |
|---|---|
| `campaign/fft_rve.py` | Moulinec–Suquet elastic FFT solver, RVE generators, elastic descriptors and weakest-link hazard |
| `campaign/pf_fft.py` | AT1 hybrid phase-field FFT solver |
| `campaign/campaign_run.py`, `pf_campaign.py`, `pf_resolution.py`, `pf_variants.py`, `pf_variant_elastic.py` | elastic and phase-field campaigns, resolution check, model variants |
| `campaign/blind/` | frozen blind-validation protocol (`blind_protocol.md`) and its SHA-256 hash and time stamp (`blind_protocol.sha256`) |
| `campaign/tcd_frozen/` | frozen protocol (`tcd_protocol.md`), analysis script (`tcd_frozen.py`) and SHA-256 hashes (`tcd_protocol.sha256`) of the prospective test of the critical-distance onset intensity |
| `campaign/blind_*.py` | generation, phase-field solves and analysis of the blind sets (decision rules evaluated exactly as frozen) |
| `campaign/descr_tools.py` and the remaining `*.py` | descriptors (ligament, minimum cut, critical-distance onset), equal-coverage statistic, conditional tests, exact bound, power analysis, tables and figures |
| `campaign/run_all.py` | single entry point |
| `campaign/environment.yml` | software environment |

Numerical outputs (tables, fields, damage maps) are not stored in the repository; they are regenerated by the
code and are available from the corresponding author (aegovalle@ubu.es) on reasonable request.

## Reproducing the results

```bash
conda env create -f campaign/environment.yml
conda activate energy-failure-descriptors
cd campaign
python run_all.py --solve -j 24   # all solves, then every table and figure (phase field: about 120 CPU-hours)
python run_all.py                 # analysis only, once the outputs exist (minutes)
```

Random seeds are fixed; solves are cached and resumable. Figures are written to `figures/`.
